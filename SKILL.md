# Блок-схемы алгоритмов в Draw.io

1. Восстанови поток из задания или кода. Сохрани все исходы решений, возвраты циклов и действия при раннем выходе.
2. Прочитай [правила построения](references/layout.md). Поставь по одному овалу «Начало» и «Конец» на краях схемы. Каждый показанный цикл обязательно обрамляй парой скошенных блоков с одинаковым названием из исходного кода. Держи действия в одной вертикальной колонке. На слиянии ветвей убери наконечники со всех входящих линий. Одну стрелку поставь на общем участке у следующего блока.
3. Сохрани редактируемый несжатый `.drawio`. Проверь структуру XML, логику по каждому пути, формы и расположение блоков. Если доступен Draw.io, проверь отрисованную схему.
4. Для документа экспортируй тот же источник через `drawio` из PATH или `/Applications/draw.io.app/Contents/MacOS/draw.io`. Получи PNG со светлым фоном, обрезкой по содержимому и масштабом около 3×. Вставь рисунок по месту в документ с сохранением пропорций и подписью по требованиям к отчёту. Сохрани `.drawio` рядом. Проверь читаемость при размере, в котором рисунок вставлен. Если экспорт не удался, сохрани источник и сообщи, что вставка ещё не выполнена.

Для отдельной схемы выдай `.drawio`. Если задача включает и Markdown, и отчёт, применяй эти правила к рисунку для отчёта.
