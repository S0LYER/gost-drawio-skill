# Установка

### Ручной вариант:

Для Linux/Mac:
```
git clone https://github.com/S0LYER/gost-drawio-skill
mv gost-drawio-skill ~/.agents/skills
```

### Автоматический вариант (через ИИ)

```
https://github.com/S0LYER/gost-drawio-skill Установи мне данный skill
```

После установки skill потребуется перезапустить ИИ-агента для того, чтобы все успешно подхватилось

> [!IMPORTANT]
> Идеальная работоспособность с другими ИИ агентами не гарантируется
